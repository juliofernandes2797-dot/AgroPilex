# AgroPilex ERP 🌱

Sistema de gestão agrícola desenvolvido para produtores rurais.

## Sobre o projeto

O AgroPilex é um ERP agrícola inicialmente focado em produtores de morango, com estrutura preparada para expansão para outras culturas.

## Módulos

- Dashboard
- Produção
- Colheitas
- Estoque
- Vendas
- Financeiro
- Compradores
- Relatórios
- Controle de usuários e permissões

## Tecnologias

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL

## Estrutura

O sistema possui controle multiempresa, permissões por usuário e banco de dados preparado para SaaS.
